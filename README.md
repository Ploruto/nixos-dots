# Laptop desktop

NixOS + Home Manager + Hyprland + a custom Quickshell desktop.
GDM remains as the login screen, with **Hyprland (uwsm-managed)** as the default;
the plain Hyprland session does not start the UWSM-bound shell services.

## Build and activate

```sh
cd ~/nixos-config
git add .
nixos-rebuild build --flake .#laptop
nix flake check
sudo nixos-rebuild switch --flake .#laptop
```

New files must be added to Git for a Git-backed flake to see them. A commit is
not required. Activation is deliberately a separate step from building.
Home Manager activation is included in the NixOS switch; no separate Home
Manager command is needed. Log out and choose the UWSM-managed session.

## Where to change things

- `hosts/laptop/desktop.nix`: shared font sizes, geometry, colors, and shortcut overrides.
- `modules/desktop-options.nix`: typed shared settings and their defaults.
- `modules/terminal.nix`: Kitty, tmux, terminal shortcuts, and terminal colors.
- `modules/hyprland.nix`: compositor settings and window/workspace shortcuts.
- `modules/session.nix`: locking, media keys, screenshots, and system controls.
- `modules/shell.nix`: shell shortcuts, generated settings, and service configuration.
- `shell/`: reusable QML components. `Config.qml` is generated by Nix.
- `hosts/laptop/configuration.nix`: hardware-independent system settings from the installation.
- `hosts/laptop/hardware-configuration.nix`: generated hardware settings.

The modules under `modules/` are flake-parts modules. They register named NixOS
and Home Manager modules under `flake.modules`. `modules/desktop.nix` selects
the components for this user's desktop. Existing installation modules are
retained as ordinary NixOS modules during this migration.

## Shared typography and theme

All font sizes are **points**. Display scaling is a separate Hyprland setting.
Maple Mono NF is installed system-wide. Terminal Neovim inherits Kitty's font;
tmux inherits the terminal font too. Maple Mono is selected only for the terminal;
other applications keep their own font settings. The bar uses
`desktop.fonts.barFamily` (Noto Sans), while the shell and lock screen use
`desktop.fonts.interfaceFamily` (Sans Serif).

Neovim is currently installed by the host configuration; no editor configuration
is managed yet.

Edit `hosts/laptop/desktop.nix`, for example:

```nix
desktop.fonts.sizes.launcher = 16;
desktop.fonts.sizes.terminal = 13;
desktop.theme.colors.accent = "#89b4fa";
desktop.geometry.padding = 12;
desktop.geometry.borderWidth = 0;
desktop.geometry.radius = 0;
desktop.geometry.gap = 0;
desktop.geometry.outerGap = 10;
desktop.geometry.spacing = 0;
desktop.windows.activeOpacity = 0.97;
desktop.windows.inactiveOpacity = 0.94;
desktop.windows.fullscreenOpacity = 1.0;
desktop.windows.blur.enable = true;
desktop.windows.blur.size = 4;
desktop.windows.blur.passes = 2;
desktop.brightness.stepPercent = 5;
desktop.brightness.fineStepPercent = 1;
desktop.brightness.fineThresholdPercent = 10;
desktop.brightness.minimumPercent = 1;
desktop.shell.bar.showLauncherIcon = false;
desktop.shell.bar.hiddenTrayIds = [ "blueman" ];
desktop.session.lockAfterSeconds = 300;
```

Colors include `#`. `desktop.theme.palette` contains Catppuccin Mocha's named
colors. Applications consume semantic `desktop.theme.colors` roles:
`background`, `panel`, `surface`, `selection`, `text`, `muted`, `accent`,
`border`, `success`, `warning`, and `error`. Rebinding one role preserves all
other defaults. Kitty, tmux, Hyprland, Hyprlock, and Quickshell use these
settings. Firefox keeps its existing profile and follows the dark preference;
its browser chrome and websites are not recolored by this palette.

Geometry is in logical pixels. Padding is separate from spacing. The laptop
currently uses 5-pixel inner gaps, 10-pixel outer gaps, a 2-pixel border,
8-pixel rounding, and 8-pixel terminal padding. Shell component spacing remains
zero, with 12 pixels of internal panel padding.

`activeBorder` follows `accent` and `inactiveBorder` follows `border` unless
overridden through `desktop.theme.colors`. Window opacity is 97% when focused,
94% when unfocused, and 100% in fullscreen. Hyprland supplies transparency and
blur so fullscreen restores opacity; Kitty itself keeps an opaque background.
Compositor opacity affects text as well as backgrounds. The solid-color
wallpaper makes blur subtle until there is other content behind a window.

## Shortcuts

Stable IDs use `category.action` and are defined in the owning feature module.
They generate both Hyprland bindings and the searchable shell action list.

```nix
desktop.shortcuts."terminal.open" = {
  description = "Open Kitty with tmux";
  keys = [ "SUPER" "Return" ];
  command = [ "kitty" ];
};
```

To rebind an existing action, include `lib` in the host module's arguments:

```nix
{ lib, ... }: {
  desktop.shortcuts."terminal.open".keys = lib.mkForce [ "SUPER" "T" ];
}
```

`command` is an argument list. For compositor actions, use a `dispatcher`
containing a trusted Hyprland Lua dispatcher expression instead. Exactly one
must be set. `enable = false` removes an action. Empty `keys` makes an action
palette-only. `repeat`, `locked`, and `confirm` are optional booleans;
confirmation is performed by the shell palette, not arbitrary direct bindings.
Duplicate enabled key combinations fail system evaluation.

Application-local mappings remain in their own application's configuration.
Tmux uses its normal `Ctrl+B` prefix, then H/J/K/L for pane focus, `|` for a
horizontal split, and `-` for a vertical split. New Kitty windows attach to
the shared tmux session `main`; `Super+Shift+Enter` opens a plain Bash terminal.

| Shortcut | Action |
|---|---|
| Super+Enter | Kitty with tmux |
| Super+Space | Applications and desktop actions |
| Super+B | Firefox |
| Super+F | Fullscreen |
| Super+Q | Close window |
| Super+H/J/K/L | Focus window |
| Super+Shift+H/J/K/L | Move window |
| Super+Ctrl+H/J/K/L | Resize window |
| Super+1…0 | Workspaces 1…10 |
| Super+Shift+1…0 | Send window to workspace |
| Super+S / Super+Shift+S | Show / send to scratchpad |
| Super+Shift+Space | Toggle floating |
| Super+C | Controls |
| Super+N | Notification history |
| Super+V | Clipboard history |
| Super+/ | Search shortcut reference |
| Super+Escape | Lock |
| Super+Shift+Escape | Session/power menu |
| Super+E | File manager |
| Print | Select screenshot region and annotate in Satty |

Panels use arrows or Ctrl+N/P, Enter to select, and Escape to close. Delete
dismisses selected notification history entries; Enter invokes their first
action when one is available. Power actions ask for confirmation. Volume and
brightness keys work independently of the shell and display an OSD when it is
running. Shutdown and restart are never executed just by opening the menu.
Brightness-down uses 5% steps above 10%, landing on 10% when crossing that
threshold, then 1% steps down to a 1% minimum. Brightness-up keeps 5% steps.
The bottom bar shows persistent workspace buttons 1–5, other occupied workspaces,
battery level, and date/time. Desktop controls remain available through shortcuts
and the command palette.

Satty opens after region selection: Enter copies and closes, Escape cancels,
and Save writes to `~/Pictures/Screenshots`. imv is the default image viewer.
Bibata Modern Ice is the cursor theme; `desktop.cursor.size` defaults to 24.

## Current scope

The custom shell provides a multi-monitor bar, image wallpaper, searchable
launcher/actions, shortcut reference, notification popups/history and DND,
clipboard selection, session menu, controls palette, and OSDs.

Detailed audio settings open Pavucontrol; networking opens keyboard-driven
`nmtui`; Bluetooth opens Blueman. These are working tools behind shell actions,
not yet custom QML settings pages. Notification history is in memory and resets
on a full shell restart. Clipboard history is text-only, stored by cliphist;
`cliphist wipe` clears it.

Hyprlock and Hypridle handle locking and inactivity independently. The shell,
idle daemon, clipboard watcher, and authentication agent are bound to
`wayland-session@hyprland.desktop.target` so they follow the Hyprland session.
The GNOME desktop is disabled. GDM and Nautilus still need some GNOME packages;
keyring storage, GVFS/removable-drive support, and laptop power profiles are
enabled explicitly instead of relying on the GNOME desktop module.

## Shell development and diagnostics

Build shell assets with `nix build .#desktop-shell`. The shell's Nix-generated
settings are copied alongside QML in that result. Keep a writable development
copy for live QML iteration; the deployed Nix store files are immutable.

```sh
systemctl --user status quickshell.service
journalctl --user -u quickshell.service -b
qs -c desktop ipc call desktop status
systemctl --user restart quickshell.service
```

Before the first activation, the implementation was tested with a full NixOS
build, Hyprland's native Lua config verifier, and a separate nested compositor
with actual panel visibility, search input, Escape dismissal, notification
delivery, IPC, and OSD checks. Real laptop suspend/resume, screen sharing, and
external-monitor hotplug still need testing in the installed session.
